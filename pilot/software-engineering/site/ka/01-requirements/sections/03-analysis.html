Section 03 Overview

Requirements Analysis

Analyze candidate requirements for clarity, completeness, binding necessity, economic QoS trade-offs, formal proof properties, and stakeholder conflict resolution.

Canonical SWEBOK Text

Requirements analysis helps software developers understand the true meaning and implications of candidate requirements. Elicited statements often represent premature solutions rather than true problems; techniques like the 5-whys help converge on underlying stakeholder needs.
