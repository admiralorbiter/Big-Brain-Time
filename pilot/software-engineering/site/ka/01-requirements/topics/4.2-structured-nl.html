Structured Natural Language Specifications

Imposes constraints on natural language to increase precision and conciseness. Common formats include Actor-Action, Use Case Templates, and User Stories.

4.2 Structured Natural Language Specifications

Canonical SWEBOK Text

Structured formats reduce ambiguity without requiring formal mathematical notation:

1. Actor-Action Format

"When [Triggering Event], [Actor] shall [Action] unless [Condition/Qualification]." Example: "When an order is shipped, the system shall create an Invoice unless the Order Terms are 'Prepaid'."

2. Use Case Template (Cockburn Format)

Specifies Use Case Name, Triggering Events, Parameters, Requires (Pre-conditions), Guarantees (Post-conditions), Normal Course, Alternative Courses, and Exception Courses.

3. User Story Format

"As a <role> I want <capability> so that <benefit>."
