System vs Software Requirements

INCOSE defines a system as an interacting combination of hardware, software, firmware, people, and facilities. System requirements constrain the entire system; software requirements apply only to the software elements within that system.

1.9 System Requirements and Software Requirements

Canonical SWEBOK Text

In complex engineering domains (e.g. autonomous vehicles, avionics, medical robotics), system requirements apply to the combination of hardware sensors, actuators, firmware, and software. Software requirements are derived by allocating system-level responsibilities to software components. In pure IT or SaaS applications, the software itself is the primary system of interest, making system and software requirements largely synonymous.
