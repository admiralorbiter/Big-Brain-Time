Software Product vs Project Requirements

Product requirements specify the expected form, fit, or function of the software artifact. Project requirements (process requirements) constrain the project constructing it (cost, schedule, staffing, testing environments, data migration).

1.3 Product vs Project Requirements

Canonical SWEBOK Text

Software product requirements specify the software's expected form, fit, or function. Software project requirements — also called process requirements or business requirements — constrain the project that constructs the software (e.g. delivery date, budget limits, user training requirements, migration windows). Project requirements are captured in project charters and managed under the Software Engineering Management KA.
