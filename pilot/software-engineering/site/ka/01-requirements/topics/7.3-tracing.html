Requirements Tracing

Documenting bi-directional links between requirements, source specifications, architecture/design elements, code units, and test cases to audit consistency and perform change impact analysis.

7.3 Requirements Tracing

Canonical SWEBOK Text

Tracing serves 2 critical purposes:

  1. Consistency Accounting: Verifies that every requirement maps forward to design elements & test cases (no missing implementation) and every design element maps backward to a requirement (no gold-plating).
  2. Change Impact Analysis: Tracing a proposed change establishes the exact "footprint" of affected requirements, design elements, code units, and test suites.
