Functional Test Case Generation Tools

Tools that mechanically derive positive and negative test cases from formally defined requirements specifications (BDD scenarios, UML statechart transition matrices).

8.3 Functional Test Case Generation Tools

Canonical SWEBOK Text

Mechanical test generation logic:

  • BDD Conversion: Converting BDD Given-When-Then scenarios into automated test suites.
  • State Model Derivation: Positive test cases are derived for each defined state transition; negative test cases are derived for state/event combinations that do not appear.

In the general case, tools generate test case inputs. Determining expected output oracles often requires human domain expertise.
