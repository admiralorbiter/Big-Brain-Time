Requirements Management Tools

Software tools for storing requirement attributes, enforcing bi-directional tracing matrices, generating documentation, and managing baseline change control workflows.

8.1 Requirements Management Tools

Canonical SWEBOK Text

Requirements management tools support foundational activities:

  • Storing requirement attributes & version histories;
  • Enforcing requirements traceability matrices across architecture, code, and tests;
  • Automating document generation & report publishing;
  • Managing change request workflows and impact analysis.

Tracing and change control are generally impractical at scale when managed through ad-hoc spreadsheets.
