9.6 Assurance Cases & Evidence Graphs

The Evidence Graph Traceability Chain
Goal → Need → Requirement → Assumption → Decision → Architecture → Code/Model → Test → Deployment → Runtime Metric → Incident → Change

Key Metadata per Trace Link

  • Why the link exists: Explicit justification and architectural rationale.
  • Who approved it: Named authority or CCB review record.
  • Supporting evidence: Test log URIs, proof outputs, or telemetry dashboards.
  • Reconsideration triggers: Operational events or metric shifts that invalidate the assumption.
