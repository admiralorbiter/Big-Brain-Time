Requirements Modeling Tools

Tools for creating, modifying, and publishing model-based specifications. Extended capabilities include Static Analysis (syntax & completeness checks), Formal Verification (Theorem Provers & Model Checkers), and Simulation.

8.2 Requirements Modeling Tools

Canonical SWEBOK Text

Categories of modeling tool capabilities:

  1. Visual Publishing & Editing: Creating UML/SysML structural and behavioral models.
  2. Static Analysis: Mechanically checking syntax correctness, completeness, and consistency.
  3. Formal Verification Tools: Theorem Provers (assisted logic proofs) and Model Checkers (exhaustive state space exploration).
  4. Simulation Engines: Dynamically executing specifications against scenario inputs.
