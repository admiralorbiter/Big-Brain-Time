# Software Engineering Pilot

This pilot focuses on analyzing, decomposing, and evaluating a Software Engineering book.

## Purpose & Research Agenda
- **Historical & Evolving Perspective:** Analyze how software engineering principles, practices, and architectural paradigms outlined in the text have aged, shifted, or been superseded by modern practices.
- **Decomposition:** Break down chapters into structured claims, concepts, and design tensions.
- **Synthesis:** Track evolving understandings and cross-chapter synthesis within Big Brain Time.

## Directory Structure
- `books/source/`: Raw PDF / source text files.
- `books/plans/`: Book split plans (YAML chapter outlines).
- `notes/`: Analytical notes and chapter breakdowns.
- `notes/synthesis/`: Cross-chapter and overarching thesis synthesis notes.
- `experiments/`: Targeted probes, exercise breakdowns, or comparison experiments.
- `projects/`: Project-level framing and context packs.
- `.bbt/records/`: Local execution, history, and evaluation tracking.
