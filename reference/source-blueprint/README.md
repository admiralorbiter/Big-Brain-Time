# Preserved Source Blueprint

This directory contains exact copies of the Big Brain Time planning and architecture files supplied for the 2026-07-27 design-studio package.

Several uploaded filenames do not match the numbered title inside the file. `../../SOURCES_AND_TRACEABILITY.md` contains the filename-to-title map. The files are preserved under their uploaded names to avoid creating false claims about canonical renaming.

These materials are evidence and prior proposals. The new design-studio documents do not silently replace or modify them.
